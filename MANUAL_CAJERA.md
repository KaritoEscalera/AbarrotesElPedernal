# Manual de Cajera

## Inicio del turno

1. Inicia sesión con tu cuenta personal.
2. Entra a **Caja** y captura el fondo inicial contado.
3. Confirma que no existan ventas pendientes de sincronizar.
4. Comprueba lector, papel e impresora con una operación de prueba autorizada.

## Realizar una venta

1. Escanea o busca cada producto.
2. Verifica descripción, cantidad y precio antes de cobrar.
3. Selecciona el método de pago.
4. Para tarjeta o transferencia, captura la referencia.
5. Para efectivo, captura lo recibido y entrega el cambio indicado.
6. En pago mixto, distribuye el total hasta que la diferencia sea cero.
7. Pulsa **Cobrar** una sola vez y espera folio o aviso de venta pendiente.

La falta de impresión no significa que la venta falló. Revisa el historial antes de
volver a cobrar.

## Sin conexión

Si aparece una venta pendiente, no borres datos ni cierres la caja. Cuando vuelva la
red pulsa **Reintentar ahora**. El identificador único evita registrar dos veces la
misma operación.

## Fiados y abonos

Selecciona al cliente correcto, confirma saldo y fecha. No uses una cuenta genérica
para fiados. Entrega comprobante después de registrar un abono.

## Cierre

1. Resuelve recargas pendientes.
2. Confirma que no haya ventas sin sincronizar.
3. Cuenta billetes y monedas por denominación.
4. Captura quién recibe el turno y cualquier diferencia.
5. Imprime el Corte Z y entrega efectivo conforme al procedimiento de la tienda.

## Prohibiciones

- No compartir contraseña.
- No repetir cobros sin revisar historial.
- No corregir inventario desde MySQL.
- No desconectar el servidor durante una sincronización o respaldo.
